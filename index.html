    The A–F rotation, and what's missing from it Essential subjects — PE, art, music, Spanish, library, technology — run on a six-day A–F rotation rather than fixed weekdays, so a scheduled day off never costs the same subject twice. Pulaski has published the calendar, and the first day, Mon Aug 24, is Day A; then B, C, D, E on Aug 25–28 and F on Aug 31.

    But the letter-to-subject mapping is blank on the form — each homeroom fills in its own. So Ms. Colletti is the one who can tell you which letter means gym shoes and which means library books. Worth asking in the same message as the after-school schedule.

    Decision point around mid-September Four after-school classes plus five-day before/after care is a lot for a brand-new kindergartner. ChicagoSMA's refund ladder: 8+ weeks before start is 100%, six weeks before through the second class is 70%, and after the second class there's no refund at all. Session 1 starts Aug 31, so the 70% window closes around mid-September. If it looks like too much, decide then — not in October.
